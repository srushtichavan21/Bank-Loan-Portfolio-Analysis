# Power BI – Bank Loan Portfolio Dashboard

## Overview
An interactive Power BI dashboard was developed to monitor loan portfolio performance, borrower profiles, and credit risk.

## Dashboard Pages

### 1. Executive Overview
- Total Loan Applications
- Total Funded Amount
- Average Interest Rate
- Average Debt-to-Income Ratio
- Loan Application Trends
- Loan Status Distribution

### 2. Loan Risk Analysis
- Good Loans vs Bad Loans
- Loan Grade Analysis
- Loan Term Analysis
- Verification Status
- Home Ownership Analysis

### 3. Borrower Insights
- Borrower Income Analysis
- Loan Purpose Analysis
- State-wise Loan Distribution
- Employment Length Analysis
- Application Type Analysis

## Power BI Features
- DAX Measures
- KPI Cards
- Interactive Slicers
- Charts and Tables
- Drill-down and Filtering

## Outcome
Created an interactive dashboard to help understand loan portfolio trends and borrower risk patterns.
