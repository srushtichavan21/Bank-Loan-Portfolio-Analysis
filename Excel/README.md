# Dataset – Bank Loan Portfolio

## Overview
This folder documents the dataset used for the Bank Loan Portfolio Analysis project.

## Dataset Information
The dataset contains bank loan application details, borrower information, loan characteristics, and payment-related fields.

## Key Columns
- Loan_ID
- State
- Application_Type
- Emp_Length
- Loan_Grade
- Home_Ownership
- Issue_Date
- Loan_Status
- Purpose
- Verification_Status
- Annual_Income
- Debt_To_Income_Ratio
- Interest_Rate
- Loan_Amount
- Total_Amount_Paid

## Data Preparation
The dataset was cleaned and prepared using Python before being used for SQL analysis and Power BI reporting.

## Note
Only share the dataset publicly if its source and licensing permit redistribution and it contains no confidential or personal borrower information.
