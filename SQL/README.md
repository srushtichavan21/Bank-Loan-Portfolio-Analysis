# SQL – Bank Loan Portfolio Analysis

## Overview
MySQL is used to analyze bank loan applications and evaluate loan portfolio performance.

## Database
- Database Name: bank_loan_db
- Table Name: bank_loan

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- CASE Statements
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- LAG and Ranking Functions
- Date Functions

## Key Analysis
1. Total Loan Applications
2. Total Loan Amount
3. Average Loan Amount
4. Good Loan and Bad Loan Analysis
5. Loan Status Distribution
6. Loan Grade and Sub-Grade Analysis
7. State-wise Loan Analysis
8. Monthly and Yearly Trends
9. Borrower Income Analysis
10. Debt-to-Income Ratio Analysis
11. Purpose-wise Loan Analysis
12. Payment Performance Analysis

## Outcome
Generated business insights using SQL queries to understand loan performance and borrower risk.
